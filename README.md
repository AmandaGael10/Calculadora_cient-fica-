# Calculadora_cientifica-

# Calculadora Científica en Python

Una aplicación en constante modificación desarrollada en Python que permite realizar operaciones aritméticas básicas como también derivadas e integrales utilizando consola.

---

##  Características Principales

* **Aritmética Básica:** Suma, resta, multiplicación y división (con validación de división entre cero).
* **Cálculo Simbólico:**
  * Cálculo de **derivadas** respecto a $x$.
  * Cálculo de **integrales indefinidas** (con constante de integración $+ C$).
  * Cálculo de **integrales definidas** evaluadas en un intervalo $[a, b]$.
* **Interfaz de Consola:** Menú interactivo basado en bucles para ejecutar múltiples operaciones continuas.

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.x**
* **[SymPy]:** Para el manejo de matemáticas simbólicas (derivadas e integrales).
* **[NumPy]:** Para manipulación y estructura de datos matriciales.
